# Steuerraum

Особистий податковий реєстр. Публічний код не містить приватних даних.

Ця версія підтримує імпорт приватного JSON-реєстру, редагування витрат, звірку категорій, HTTPS-посилання на документи, CSV та JSON-резервні копії. Дані зберігаються лише в браузері (localStorage), не синхронізуються між пристроями. Зберігайте резервні копії в OneDrive. Інтеграція Microsoft ще не реалізована.
